# Lib-PluginKit

Lib-PluginKit is a design-stage C++20 toolkit for application plugins. Applications define ordinary C++ interfaces. The toolkit generates the bindings and manages plugin discovery, installation, execution, and updates.

The [design document](docs/design.md) specifies the public API, plugin SDK, package format, worker process, and `hpk` tooling.
